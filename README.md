# QueueCare

QueueCare is a web-based Clinic Appointment and Queue Management System.

## Project Description

The application aims to simplify patient appointment booking, doctor scheduling and clinic queue management.

## Technology Stack

- Python 3.13
- Flask 3.1.3
- HTML
- CSS
- Bootstrap
- MySQL
